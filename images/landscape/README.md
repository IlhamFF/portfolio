# Landscape Photos

Folder ini untuk menyimpan foto-foto landscape Anda.

## Format yang Disarankan
- Resolusi minimal: 1920x1080 atau lebih tinggi
- Format: JPG atau PNG
- Aspect ratio: 16:9 atau landscape lainnya

## Cara Menggunakan
1. Simpan foto landscape Anda di folder ini
2. Beri nama file dengan format: `landscape-1.jpg`, `landscape-2.jpg`, dst.
3. Update file `script.js` pada fungsi `initLandscapeCarousel()` untuk menggunakan foto-foto ini

Saat ini carousel landscape menggunakan foto yang sama dengan carousel portrait sebagai placeholder.
