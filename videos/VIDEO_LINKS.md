## 📝 Cara Mengisi Link

### 1. YouTube
```
https://youtube.com/watch?v=VIDEO_ID
atau
https://youtu.be/VIDEO_ID
```

### 2. Vimeo
```
https://vimeo.com/VIDEO_ID
```

### 3. Google Drive
```
https://drive.google.com/file/d/FILE_ID/view
```

### 4. Instagram
```
https://www.instagram.com/reel/REEL_ID/
```

## 🔄 Setelah Mengisi Link

Setelah Anda mengisi semua link di tabel di atas, beri tahu saya dan saya akan:
1. Update `index.html` dengan link yang benar
2. Tambahkan video-video baru ke gallery videography
3. Sesuaikan layout jika perlu

---

## 💡 Tips

- **YouTube**: Ambil link dari tombol "Share" → Copy link
- **Google Drive**: Klik kanan file → Get link → Copy link
- **Instagram**: Buka reel → Klik titik tiga → Copy link
- Pastikan link bisa diakses publik (tidak private)
